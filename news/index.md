# Changelog

## isocountry 0.8.0

- `isocountry` now uses the ISO 3166-1 name “Naoero” for Nauru (NR).

## isocountry 0.7.0

CRAN release: 2026-08-21

- Updated the `isocurrency` data to the latest version (2026-08).

## isocountry 0.6.1

CRAN release: 2026-06-29

- The `isocurrency` data now includes Eswatini (currency code SZL),
  which was previously dropped due to a country name mismatch (the
  source still lists it as “Swaziland”).
